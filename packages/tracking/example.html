The tracking script automatically detects:

  • Page views (automatically tracked)
  • Click events on all elements
  • Scroll events with depth calculation
  • Mouse movements for heatmap data
  • Page unload events (using beacon API)

Technical Features

  • High Performance: Minimal impact on page load
  • Reliable Delivery: Uses beacon API for page unload
  • Privacy Focused: No cookies, uses fingerprinting
  • Throttled Events: Mouse movements limited to 10/second
  • Batched Sending: Events sent in batches for efficiency
  • ES5 Compatible: Works in all browsers
